# ប្រព័ន្ធគ្រប់គ្រងទិន្នន័យគ្រូបង្រៀន - សាលារៀនជំនាន់ថ្មី (NGS)
### រៀបចំឡើងជាពិសេសជូនចំពោះ៖ **លោកគ្រូ នួន បូណង (Bonorng11)**

ប្រព័ន្ធនេះត្រូវបានរចនាឡើងដោយច្របាច់បញ្ចូលគ្នារវាង៖
1. **រចនាបទ និងឧបករណ៍បង្រៀនទំនើប** ពីប្រព័ន្ធវិទ្យាល័យព្រះស៊ីសុវត្ថិ NGS (`report.khmermath.org`)
2. **ប្រព័ន្ធគ្រប់គ្រង និងស្ថិតិទិន្នន័យសាលារៀន** ពីប្រព័ន្ធវិទ្យាល័យបឹងត្របែក NGS (`phaijohn6629.github.io`)

2. ប្រព័ន្ធនឹងដំណើរការភ្លាមៗយ៉ាងរលូន!

## 🛠️ មុខងារសំខាន់ៗដែលមានក្នុងប្រព័ន្ធ

1. **ផ្ទាំងដើម (Dashboard):**
   - បដាស្វាគមន៍ (Hero Banner) ជាមួយរូបតំណាង 3D និងឈ្មោះលោកគ្រូ **Bonorng11**
   - នាឡិកា Live Clock បង្ហាញម៉ោង និងពេលបច្ចុប្បន្នស្វ័យប្រវត្តិតាមម៉ោងកុំព្យូទ័រ
   - ឧបករណ៍បង្រៀនរហ័ស៖ ហៅឈ្មោះសិស្ស, កង់ចាប់ឈ្មោះ (Lucky Wheel), នាឡិកាកំណត់ពេល (Classroom Timer)
   - កំណត់ចំណាំ & កិច្ចការផ្សេងៗ (Quick Task Logger)៖ ប្រជុំ, ប្រចាំការ, ត្រួតប្រឡង, ការងាររដ្ឋបាល, ជួយសិស្ស រួមជាមួយការរាប់ចំនួនថ្ងៃជាប់គ្នានៃភាពសកម្ម (Streak 🔥)
   - ក្រាហ្វិកម៉ោងបង្រៀនប្រចាំសប្ដាហ៍ (Listening Overview)
   - ក្រាហ្វិកកម្រិតគុណភាពបង្រៀន ៥០ ពិន្ទុ NGS (Top Genres Donut Chart)

2. **កាលវិភាគបង្រៀន (Schedule):**
   - តារាងម៉ោងបង្រៀនតាមថ្ងៃ ចន្ទ ដល់ សៅរ៍ តាមបន្ទប់ និងតាមថ្នាក់នីមួយៗ

3. **ស្រង់វត្តមានសិស្ស (Attendance Roll Call):**
   - ស្រង់វត្តមានងាយស្រួលដោយចុច៖ **វត្តមាន**, **ច្បាប់**, ឬ **អវត្តមាន**
   - មានប៊ូតុង «វត្តមានទាំងអស់ (Mark All Present)» ដើម្បីស្រង់រហ័ស

4. **បញ្ចូលពិន្ទុ & ចំណាត់ថ្នាក់ (Gradebook & Ranking):**
   - បញ្ចូលពិន្ទុតេស្តប្រចាំខែ (Q1, Q2) និងពិន្ទុឆមាស (Midterm, Final)
   - ប្រព័ន្ធគណនាពិន្ទុសរុប (១០០), និទ្ទេស (A, B, C, D, E, F), និងចំណាត់ថ្នាក់ (#1, #2, ...) ស្វ័យប្រវត្តិ
   - អាចបន្ថែមសិស្សថ្មី ឬលុបសិស្សបាន
   - មានប៊ូតុង **ទាញយកជា Excel/CSV** ដោយចុចតែម្តង

5. **កិច្ចតែងការបង្រៀន (Lesson Plans):**
   - ផ្ទុក និងតាមដានកិច្ចតែងការតាមស្តង់ដារ ៥ ជំហាន NGS
   - មាន Link ភ្ជាប់ទៅកាន់ Google Drive ដោយផ្ទាល់

6. **ស្នាដៃ & Portfolio:**
   - កត់ត្រាវិញ្ញាបនបត្រ ការស្រាវជ្រាវ និងការអភិវឌ្ឍវិជ្ជាជីវៈ

7. **ឧបករណ៍បង្រៀន (Classroom Tools):**
   - **កង់ចាប់ឈ្មោះសិស្ស (Lucky Wheel):** មានសំឡេងរោទ៍ tick-tick និងកាំជ្រួចអបអរសិស្សដែលត្រូវជ្រើសរើស
   - **នាឡិកាកំណត់ពេល (Classroom Timer):** មានសំឡេងរោទ៍ពេលអស់ម៉ោង និង Preset (១នាទី, ៣នាទី, ៥នាទី, ១០នាទី)

8. **ការបម្រុងទុកទិន្នន័យ (Backup & Restore):**
   - រាល់ទិន្នន័យត្រូវបានរក្សាទុកក្នុងកុំព្យូទ័រ (LocalStorage) មិនបាត់បង់ពេលបិទ Browser
   - មានប៊ូតុង **ទាញយក JSON Backup** ទុកជាឯកសារសុវត្ថិភាព
   - អាច **Import Restore** មកវិញបានគ្រប់ពេលវេលា

9. **ការផ្លាស់ប្ដូរពណ៌ផ្ទៃ & បោះពុម្ព:**
   - ប៊ូតុង Dark / Light Mode
   - ប៊ូតុងបោះពុម្ព (Print) ដែលរៀបចំទម្រង់ឯកសារយ៉ាងស្អាតសម្រាប់ព្រីនចេញជាក្រដាស

ប្រសិនបើលោកគ្រូចង់ឱ្យប្រព័ន្ធនេះដំណើរការជា Link លើអ៊ីនធឺណិតដូចជា `https://bonorng.github.io/teacher-dashboard`៖
1. បង្កើត Repository ថ្មីមួយលើ GitHub របស់លោកគ្រូ
2. Upload ឯកសារទាំងអស់ក្នុង folder នេះ (`index.html`, folder `css`, folder `js`)
3. ចូលទៅ **Settings -> Pages** ហើយជ្រើសរើស **Branch: main** រួចចុច **Save**
4. លោកគ្រូនឹងទទួលបាន Link គេហទំព័រផ្ទាល់ខ្លួនសម្រាប់ប្រើប្រាស់បានគ្រប់ទីកន្លែង!
